# InstanceHarbor 1.0.0

Windows x64 ZIP 請完整解壓後執行 InstanceHarbor.exe。Setup 為目前使用者安裝並建立開始選單捷徑。
Windows 需有 WebView2 Runtime。1.0.0 起執行檔靜態連結 Visual C++ 執行階段，不再需要 Visual C++ 可轉散發套件。
便攜版的安裝說明在 `WINDOWS-GETTING-STARTED.txt`。啟動 Minecraft 實例需準備相容 Java。Setup 尚未簽章。

ZIP 與 Setup 共用本機正式工作區。升級前請備份設定與實例資料，並正常停服、關閉視窗、退出該工作區的 Manager。
Setup 解除安裝會保留工作區。便攜工具可從已登記的前版回退。

## 自 1.0.0-rc2 以來的變更

- 伺服器後台：正式版附帶固定版本的 ConPTY 執行階段，伺服器在 InstanceHarbor 自己的後台執行，可直接輸入指令。
- 介面：預設跟隨系統語言，不支援的語言改用英文。啟動錯誤以對話框顯示；批次啟動的失敗會立即列出，其他伺服器繼續啟動。停止期間顯示「停止中」。多選時，啟動、停止與重新啟動按鈕會顯示各自影響幾台。
- 世界設定：伺服器正常停止後，尚未送出的遊戲規則會寫入世界存檔。
- Java：登記的 Java 不存在時明確回報，修正後可以重新啟動。
- 管理資料夾：可以選擇工作區以外的任意本機資料夾。工作區內部資料夾、包含工作區的上層資料夾、磁碟根目錄與 UNC 路徑仍會拒絕。
- Velocity：可以監聽所有介面（`0.0.0.0`），需要明確確認，詳細面板會顯示警告。
- 伺服器核心：
  - 核心 JAR 不限檔名，登記時記下實際檔名；檔案換名後，啟動前會重新尋找。
  - 內建清單沒有的 Paper、Folia、Velocity，會以 PaperMC 官方清單核對 SHA-256。
  - 離線時，或遇到 Purpur 等 Paper 分支、Spigot，改以 JAR 自述的版本選擇 Java 並顯示警告，不會拒絕。
  - 核心被其他程式開著（例如伺服器仍在執行）時，會明確回報。
- V1 伺服器：新增 CLI 指令，把 V1 管理的伺服器原地移交給 1.0，也可以回退。步驟見[開發指南](development.md)的「從 V1 移交伺服器」。
- 1.0 的資料位置與工作區格式名稱已定案，詳見[開發指南](development.md)。

## 從 1.0.0-rc2 升級

直接執行 1.0.0 Setup 即可更新。rc2 建立的工作區由 1.0 照常開啟且不改寫格式值，所以仍可回退到 rc2；1.0 新建的工作區 rc2 無法開啟（`UnsupportedWorkspace`）。
要回退到 rc2 時，若曾關閉「關閉視窗時縮到系統匣」，請先重新開啟並儲存，否則 rc2 無法讀取外觀設定。
1.0 不再使用 `%LOCALAPPDATA%\local.instanceharbor.v2`（舊版的 WebView2 介面快取），可以手動刪除。

此公開版本使用合成路由資料。建服仍能驗證並準備 LuckPerms 核心插件；預設不替任何身分授予權限。
請由使用者自行管理伺服器權限。
