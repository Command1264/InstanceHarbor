# InstanceHarbor 1.0.1

1.0.0 的修正版。系統需求、安裝方式與工作區格式都和 [1.0.0](windows-1.0.0.md) 相同。

## 修正

- 已停止的實例不再從實例清單消失。
  - **症狀**：清單上方出現「部分實例無法核對」，該實例顯示「實例狀態無法核對」，也無法操作。
  - **原因**：Windows 會重複使用程序編號（PID）。實例上次執行的 Host 程序編號，後來被其他帳號的程序（例如系統服務）使用。查詢這個程序時 Windows 拒絕存取，1.0.0 把這個錯誤當成無法判斷。
  - **修正**：1.0.1 把「拒絕存取」判定為原本的程序已經結束。其他無法判斷的情況仍會阻擋操作，避免同一個世界被重複啟動。

## 從 1.0.0 升級

1. 正常停止伺服器。
2. 關閉 InstanceHarbor 視窗，並從系統匣結束 Manager。
3. 執行 1.0.1 Setup。

工作區格式沒有改變，可以回退到 1.0.0。
