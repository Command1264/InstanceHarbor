# 領域文件

InstanceHarbor 採單一脈絡：根目錄的 `GLOSSARY.md` 記錄專案用語，`docs/adr/` 按需記錄架構決策。

## 探索前閱讀

- 先讀根目錄的 `GLOSSARY.md`，再讀與目前工作相關的 `docs/adr/` 文件。
- 若某份 ADR 或目錄尚不存在，直接繼續；不要為了完成設定而預先建立空白 ADR。
- 若未來專案真的拆成多個脈絡，另行規劃 `GLOSSARY-MAP.md` 與各脈絡的文件位置，並同步更新本文件。

## 用語與決策

- 在工作項目、規格、測試與程式設計中，沿用 `GLOSSARY.md` 定義的用語，避免它明確排除的同義詞。
- 新概念若尚未列入用語表，先確認是否真有新邊界；需要時再更新 `GLOSSARY.md`。
- 提案若牴觸既有 ADR，明示衝突及重新評估的理由，不要默默覆蓋既有決策。
