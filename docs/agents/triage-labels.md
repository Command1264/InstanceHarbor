# Triage 標籤

工程 skill 使用下列五種角色。請在 GitHub Issue 使用對應的標籤。

| Skill 角色 | GitHub Issue 標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待維護者評估 |
| `needs-info` | `needs-info` | 等待提出者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格足夠，Agent 可處理 |
| `ready-for-human` | `ready-for-human` | 需要人工實作或處理 |
| `wontfix` | `wontfix` | 不予處理 |

Skill 提到角色時，使用表中對應的 GitHub Issue 標籤。若日後實際標籤名稱改變，更新此表的對應值。
