InstanceHarbor — Windows x64

1. Extract the entire ZIP to one folder and open InstanceHarbor.exe.
   The PowerShell CLI is ihctl.exe.
2. InstanceHarbor needs the Microsoft Edge WebView2 Runtime. If it is missing,
   InstanceHarbor says so each time it starts. Install Microsoft's
   "Evergreen Standalone Installer" for x64 from the official page, then open
   InstanceHarbor again.
   https://developer.microsoft.com/microsoft-edge/webview2/#download-section
   No Visual C++ Redistributable is needed.

繁體中文
1. 完整解壓 ZIP，再開啟 InstanceHarbor.exe。PowerShell CLI 為 ihctl.exe。
2. InstanceHarbor 需要 Microsoft Edge WebView2 Runtime。缺少時，每次啟動都會提示。
   請從上方 Microsoft 官方頁面安裝「Evergreen 獨立安裝程式」的 x64 版，
   再重新開啟 InstanceHarbor。不需要另外安裝 Visual C++ 可轉散發套件。
